# 0003 — keep-requested-default-thresholds

## Status

Accepted

## Date

2026-08-04

## Context

러너 발주 사양은 CLI 기본값을 conf 0.25 / IoU 0.45로 지정했다. 반면 모델 배포 패키지
[README](../../model/bammasil_det_c4b_loli0_640/README.md)는 conf **0.35** / IoU **0.7**을
권장하며 "임계값을 바꾸면 성능표와 비교가 깨진다"고 명시한다 — 계약 충돌.

실측으로도 차이가 확인됐다: 샘플 영상에서 conf 0.25일 때 도로 아스팔트를 `stairs 0.34`로
오탐하는데, 이는 모델 카드가 경고한 기지 오탐 유형이고 conf 0.35면 걸러진다.

## Decision

CLI 기본값은 발주 사양대로 conf 0.25 / IoU 0.45를 유지한다 (요구사항 우선순위:
현재 요청 > 계약 문서). 두 값 모두 CLI 인자로 노출되어 있으므로, 모델 카드 성능표와
비교하는 실행에서는 `--conf 0.35 --iou 0.7`을 명시하면 된다. 이 사실을
`docs/RUNNER_SPEC.md`의 인자 표와 `--help` 문구에 병기한다.

## Considered Options

1. **발주 사양 기본값(0.25/0.45) + 모델 카드 권장값 병기** — 요청 우선, 정보 손실 없음
2. 모델 카드 권장값(0.35/0.7)을 기본값으로 채택 — 발주 사양을 조용히 덮어쓰게 됨
3. 기본값 없이 필수 인자화 — 인터페이스 계약(재실행 명령에 conf/iou 없음)을 깨뜨림

## Consequences

- 기본값 실행 결과는 모델 카드 성능표와 직접 비교할 수 없다 (임계값이 다름).
- 저조도 오탐(도로→stairs 등)이 기본값에서 더 많이 보일 수 있다 — 러너 결함이 아니라
  임계값 차이임을 인지할 것.

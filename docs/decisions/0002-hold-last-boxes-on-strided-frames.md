# 0002 — hold-last-boxes-on-strided-frames

## Status

Accepted

## Date

2026-08-04

## Context

`--stride N`은 영상에서 N프레임마다만 추론한다 (실제 파이프라인의 cadence 설계와 동일 구조).
추론하지 않은 프레임을 어떻게 렌더할지 — 빈 프레임 / 직전 박스 유지 / 보간·추적 — 를
정해야 한다.

## Decision

추론하지 않은 프레임은 **직전 추론 결과의 박스를 좌표 그대로 유지**해 렌더한다.
보간·모션 추적은 하지 않는다. `run.jsonl`에는 유지 프레임을 `inferred: false, ms: null`로
기록해 실측과 유지본을 구분하고, `[det]` 집계는 추론 프레임만 센다 (중복 집계 방지).

## Considered Options

1. **직전 박스 좌표 그대로 유지** — 요구사항("직전 박스를 유지해서 렌더")의 가장 직접적
   구현. 실제 파이프라인에서 cadence 간격 동안 사용자가 보게 될 화면과 같아 관찰 가치가 있음
2. 미추론 프레임은 박스 없이 렌더 — 결과 영상이 깜빡거려 cadence 설계 관찰이 불가
3. 광류·칼만 등으로 박스 보간 — 요구 범위 밖, 러너의 목적(구동 확인)에 과함

## Consequences

- stride가 크고 피사체가 빠르면 유지 프레임의 박스가 실제 위치에서 벗어난다 —
  이는 cadence 설계가 감수하는 지연을 그대로 보여주는 것으로, 러너에서는 의도된 동작이다.
- `run.jsonl`의 `inferred` 플래그로 후분석 시 실측만 걸러낼 수 있다.

## 데이터

보행자·볼라드는 AIHub 인도보행 데이터, 계단은 StairNet을 사용했습니다. 합성 저조도 데이터 중심으로 학습했을 때 실제 야간 성능이 부족해 NightOwls의 야간 보행자 데이터를 추가했습니다.

### 배경 이미지로 계단 오탐 줄이기

기존 프로젝트에서는 계단이 없는 보도에서도 계단이 검출되는 오탐을 줄이기 위해 배경 이미지를 학습에 추가했습니다. 탐지 대상이 없는 이미지를 빈 라벨과 함께 넣는 negative 학습입니다.

본선 실험에서는 AIHub 보도 배경 1,163장을 추가했고, 야간 계단 오탐은 22건에서 9건으로 줄었습니다. [실험 기록](MODEL_EXPERIMENTS.md)

### 후속 실험의 데이터 구성

이번 YOLO26 학습셋에는 빈 라벨 이미지 926장이 포함돼 있습니다. 다섯 모델 모두 같은 분할을 사용했으며, 클래스는 `0 person`, `1 stairs`, `2 bollard`입니다.

| 용도 | 이미지 수 | 비고 |
|---|---:|---|
| 학습 | 10,919 | 기존 리샘플링 데이터 |
| 개발 검증 | 787 | best checkpoint 선택 |
| 기존 볼라드 평가 | 2,146 | 과거 결과와 비교 |
| 개발셋 중복 제외 볼라드 평가 | 2,085 | 중복 61장 제외 |
| 야간 사람 평가 | 1,001 | NightOwls rec34 |

학습·개발셋의 동일 이미지 중복은 없습니다. 야간 볼라드와 보행 시점의 원거리 계단은 추가 검증이 필요합니다.

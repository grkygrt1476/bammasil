# 모델 실험 기록

기존 팀 프로젝트의 negative 학습 기록과 2026년 10월 7일 완료한 YOLO26 실험을 정리했다. 2026년 11월 23일 저장된 체크포인트와 완료 기록을 다시 대조했으며, 문서 작성 중 새 학습이나 평가는 실행하지 않았다.

## 배경 데이터와 negative 학습

계단이 없는 보도에서 계단이 검출되는 문제를 줄이기 위해, 기존 프로젝트에서 AIHub 보도 배경을 추가했다. 탐지 대상이 없는 이미지에 빈 라벨을 주어 배경도 학습에 포함하는 방식이다.

본선 발표 26쪽에는 배경 1,163장을 추가했을 때 야간 계단 오탐이 22건에서 9건으로 줄었다고 기록돼 있다. 이는 당시 팀 실험의 보고값이다. 해당 슬라이드만으로는 평가 이미지 수, confidence, 매칭 규칙을 확인할 수 없어 오탐률이나 새 실험의 재현 결과로 표현하지 않는다.

이번 YOLO26 분할은 학습 10,919장 중 빈 라벨 926장, 개발 787장 중 빈 라벨 74장을 포함한다. 발표 자료의 추가 수량과 이번 분할의 수량은 서로 다른 기록이며, 정확한 일대일 대응을 확인한 것은 아니다. 또한 빈 라벨만으로 이미지에 대상 객체가 실제로 없다고 보장할 수는 없다.

다섯 YOLO26 조건은 같은 분할로 학습했다. 이번에는 배경 포함/제외 대조군을 따로 학습하지 않았으므로 negative 학습의 효과를 분리해 주장하지 않는다.

## YOLO26 비교 조건

- 입력: n/s/m 640, n/s 960
- 공통: 50 epochs, batch 16, seed 0, 학습 10,919장 / 개발 787장
- 환경: Windows, RTX 4080 SUPER 16GB
- 선택: 개발셋 mAP50–95 기준 best checkpoint
- 기록: 설정·결과·가중치 및 데이터 manifest 해시를 [결과 JSON](experiments/yolo26-summary.json)에 보관

## 공개 실험 근거

[실행별 설정·결과·곡선·해시](experiments/README.md)에서 다섯 실험의 원본 추출 기록을 확인할 수 있다. [집계 CSV](experiments/comparison.csv)는 아래 표의 최종 best 검증값을 담고 있다.

## 개발셋 결과

| 조건 | mAP50–95 | 학습 경과(분) | 최대 allocated VRAM(GiB) |
|---|---:|---:|---:|
| n640 | 0.59884 | 83.4 | 2.42 |
| s640 | 0.63822 | 88.0 | 4.52 |
| m640 | 0.64738 | 118.3 | 8.56 |
| n960 | 0.61995 | 102.3 | 5.45 |
| s960 | 0.66632 | 134.6 | 10.04 |

각 run의 완료된 `progress.json`에 기록된 best 내장 재검증 결과다. 별도 평가기의 `evaluation/dev.json`은 실행 조건이 달라 이 표에 섞지 않았다. 개발셋은 checkpoint 선택에도 사용됐고 각 조건은 seed 0 한 번이다. 학습 시간은 초기화·내장 검증·저장 등을 포함하며 스마트폰 추론 시간을 뜻하지 않는다.

## 외부 평가 범위

n640·m640에는 기존 볼라드 2,146장, 개발셋 중복 61장을 제외한 볼라드 2,085장, NightOwls rec34 1,001장의 별도 평가 기록이 있다. 2026년 11월 23일 나머지 세 후보의 볼라드 2,085장·야간 사람 1,001장 평가를 완료했다. [입력 640 고정 비교 결과](experiments/external-640/README.md)

볼라드 평가와 rec34는 과거에도 사용한 회귀 평가셋이다. rec34는 person 전용이며 혼합 ignore 영역을 기본 평가기가 마스킹하지 않는 한계가 있다. 야간 볼라드와 실제 보행 시점의 원거리 계단은 별도 검증이 필요하다.

## 다음 검증

1. 입력 640 고정 AP 비교에 이어, 960 입력과 고정 confidence의 오탐·미탐을 비교한다.
2. negative 학습 효과를 다시 확인하려면 같은 모델·seed·평가셋에서 배경 포함/제외 조건을 따로 구성한다. 기존 결과와 섞지 않는다.
3. 변환 후 정확도와 스마트폰 전체 지연시간을 측정해 후보를 좁힌다.

결과 JSON의 run ID와 원본 해시는 로컬 기록을 추적하기 위한 값이다. 원본 로그·이미지·가중치가 GitHub에 포함된다는 뜻은 아니며, 학습·평가 명령은 [재현 절차](REPRODUCE_YOLO26.md)에 정리했다.
